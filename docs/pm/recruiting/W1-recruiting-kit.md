## 筛选问卷（5 题）

请在 Google Form / 飞书问卷 / Typeform 上配置：

1. **您的当前职位 / 行业**（开放）
2. **以下哪项最符合您的编程经验？**
   - [ ] 完全不会编程，没写过代码
   - [ ] 会写 Excel 公式 / 简单 SQL
   - [ ] 会用 Python / R 做过分析
   - [ ] 是工程师 / 开发者
3. **您日常工作里，业务规则一般怎么"落地"？**（多选）
   - [ ] 写在 Word / Excel / 飞书文档里
   - [ ] 提需求给工程师写代码
   - [ ] 用低代码 / BI 工具配置
   - [ ] 在专门的规则引擎里
   - [ ] 其他：___
4. **您方便在哪些时段参加 60 分钟测试？**（多选 工作日 vs 周末，上午 / 下午 / 晚上）
5. **联系方式**：邮箱、微信号、手机号

**筛选规则**：
- 第 2 题选 ① 或 ② → 优先（**P1/P2/P5 候选人必须从这里出**）
- 第 2 题选 ③ → 收 1–2 人作为 P3/P4
- 第 2 题选 ④ → 拒绝（不是目标用户）
- 第 1 题在风控/合规/政策/审核/产品 → 优先

## 招募渠道清单

| 渠道 | 优先级 | 备注 |
|---|---|---|
| 现有 SaaS 试用客户中的非工程角色 | ★★★ | 已注册 + 有兴趣，转化率最高 |
| 投资人 / 顾问网络（请投资人推荐组合 portfolio 公司的合规） | ★★★ | 信任传递 |
| 知乎付费招募（关键词：合规、风控、政策） | ★★ | 1–2 天可招到 5–10 人，需付费过滤 |
| LinkedIn 私信（合规官 / 风控总监） | ★★ | 转化慢，但样本质量好 |
| 用研平台（dscout / UserInterviews） | ★ | 国内可用性差 |
| 朋友圈 / 微信群（金融科技、合规） | ★ | 报酬可降到 ¥300，覆盖广 |

**预算**：5 人 × ¥500 + 备份 1 人 × ¥500 = ¥3,000；问卷 + 招募平台预留 ¥2,000；合计 ≤ ¥5,000。

## 主持人脚本（开场词 90 秒）

> 您好 [姓名]，欢迎参加 Aster 用户体验测试。我是 [主持人]，我旁边的 [记录员] 全程记录，不会插话。
>
> 三件重要的事：
>
> 1. **我们在测试产品，不是测试您**。任何卡顿、报错、看不懂的地方都是产品的问题。
> 2. **请边做边把想法说出来**，越啰嗦越好——"咦这个按钮为什么在这儿"、"这个词我看不懂"、"我感觉应该这样做"——都说出来。
> 3. **我们会录屏**（您已经签过同意书）。录屏只在我们团队内部用，2026-12-31 前删除。
>
> 60 分钟里有 4 个任务，做不完没关系。如果您卡住超过 3 分钟，我会给您一个提示。
>
> 我们准备好开始了吗？
>
> （**关键**：从这一刻起，30 秒内不要主动说话。让用户开口。）

## 录屏与同意书

录屏存放：内部 OneDrive `aster-research/usability-2026-W3/` 文件夹，权限：产品 + 设计 + 工程负责人。

同意书要点：
- 录屏内容（视频 + 音频 + 屏幕）
- 用途：仅产品改进，不公开传播
- 保留期：至 2026-12-31，到期销毁
- 可随时撤销同意（撤销后立即删除已录内容）

模板已建在 `recruiting/consent-form.md`（见下文）。

## 风险与备份

| 风险 | 触发概率 | 应对 |
|---|---|---|
| 招到的人临场放鸽子 | 中 | 多备 1 人（Pilot 做正式备份） |
| 飞书会议网络问题 | 低 | 备 Zoom 链接；主持人提前 10 min 进会 |
| 主持人或记录员请假 | 低 | 每场指定 backup |
| 测试中产品 bug | 中 | 提前 24h 跑 smoke test；准备 fallback prompt 和"假装一切正常"过场话术 |
